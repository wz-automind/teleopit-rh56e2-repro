# 安装与运行（快速入口）

本页只保留最常用的安装和启动命令。环境准备、PICO 配置、只读预检、
单自由度测试、急停和故障处理，请以[完整中文使用手册](USAGE.zh-CN.md)为准。

## 1. 统一使用一个环境

安装、验证、仿真和真机均使用 `/home/unitree/miniforge3` 中名为
`teleopit` 的环境。安装器会向当前激活的环境安装依赖，不会再创建第二套环境。

## 2. 全新安装与离线检查

```bash
source /home/unitree/miniforge3/bin/activate
conda create -n teleopit python=3.11 -y
source /home/unitree/miniforge3/bin/activate teleopit

git clone https://github.com/wz-automind/teleopit-rh56e2-repro.git
cd teleopit-rh56e2-repro
bash scripts/setup/install.sh --profile sim --download-pico-apk
bash scripts/dev/validate.sh
```

安装器会检出仓库固定的 Teleopit、somehand 和 pico-bridge 版本，应用
RH56E2 overlay，并下载模型、GMR、策略和 PICO APK。安装目录默认为
`~/Teleopit`。

## 3. G1 + 双 E2 仿真

```bash
source /home/unitree/miniforge3/bin/activate teleopit
cd ~/Teleopit

python scripts/run/run_sim_rh56e2.py \
  --config-name pico4_sim_rh56e2 \
  controller.policy_path=ckpt/track_g1.onnx
```

仿真不会向实体 RH56E2 写入指令。

## 4. Unitree 主机真机命令

以下两个命令使用你的部署路径、PICO 地址和 `eth1`。先激活环境：

```bash
source /home/unitree/miniforge3/bin/activate teleopit
cd /home/unitree/Teleopit
```

### 4.1 全身遥操，不包含灵巧手

```bash
python scripts/run/run_sim2real.py \
  --config-name pico4_sim2real \
  controller.policy_path=ckpt/track_g1.onnx \
  input.bridge_advertise_ip=192.168.50.62 \
  real_robot.network_interface=eth1
```

### 4.2 全身遥操，包含左右 E2

```bash
python scripts/run/run_sim2real.py \
  --config-name pico4_sim2real_rh56e2 \
  controller.policy_path=ckpt/track_g1.onnx \
  input.bridge_advertise_ip=192.168.50.62 \
  real_robot.network_interface=eth1 \
  hands.rh56e2.left_host=192.168.123.210 \
  hands.rh56e2.right_host=192.168.123.211 \
  hands.rh56e2.port=6000 \
  hands.rh56e2.write_enabled=true
```

这两个命令二选一，不能同时运行。第二个命令会真实写入左右 E2；必须先完成
完整手册第 11–14 节的只读检查、单自由度测试和 G1 独立站立验收。

## 5. 真机前最低检查

```bash
cd ~/teleopit-rh56e2-repro
bash scripts/dev/check_unitree_g1_rh56e2.sh
```

当前验证参数是 `eth1` / `192.168.123.164`、左手
`192.168.123.210:6000`、右手 `192.168.123.211:6000`、PICO 主机地址
`192.168.50.62`。检查命令只用 Modbus FC03 读取遥测，不执行 FC16 写入。
必须确认两侧数据可读、故障为零、温度正常且左右手地址不同，才能启动：

```bash
ENABLE_G1_REAL=YES ENABLE_RH56E2_WRITES=YES \
  bash scripts/run/run_unitree_g1_rh56e2.sh
```

上述值都可用同名环境变量覆盖，完整手册同时保留 `.11.x` 通用组网示例和外部
主机运行方法。`g1_host_cli` 与 Teleopit 控制进程不能同时运行。
