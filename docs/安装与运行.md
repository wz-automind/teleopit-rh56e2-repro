# 安装与运行

## 1. 环境

推荐在运行 G1 的 Linux 主机上使用：

- Ubuntu 22.04/24.04 x86_64
- Python 3.10 或 3.11
- PICO 4 与运行主机处于同一局域网
- 真机时，G1 网卡和 RH56E2 网卡/网段均已规划


## 2. 一次安装

```bash
git clone https://github.com/wz-automind/teleopit-rh56e2-repro.git
cd teleopit-rh56e2-repro
bash scripts/install.sh --profile sim --download-pico-apk
```

默认安装位置：

- Teleopit：`$HOME/Teleopit`
- somehand：`$HOME/Teleopit/third_party/somehand`
- 虚拟环境：`$HOME/Teleopit/.venv`

可以通过环境变量改目录：

```bash
TELEOPIT_DIR=/opt/Teleopit \
SOMEHAND_DIR=/opt/Teleopit/third_party/somehand \
bash scripts/install.sh --profile sim --asset-source huggingface
```

脚本会拒绝修改没有 `.rh56e2-overlay` 标记的脏上游工作树，避免覆盖其他实验改动。

## 3. PICO 端

按照 pico-bridge v0.2.1 中文文档：

1. 让 PICO 和主机位于同一局域网。
2. 在 PICO 中关闭安全边界，并开启手柄/手势自动切换。
3. 安装 `downloads/PicoBridge_v0.2.1_20260522_release.apk`；安装脚本已经校验 SHA-256。
4. 确认 PICO 应用显示的主机 IP 与实际接收端一致。

## 4. 离线验证

```bash
TELEOPIT_DIR="$HOME/Teleopit" bash scripts/validate.sh
```

验证内容包括：

- Python 源码编译与 9 项 Modbus/映射单元测试；
- 合并后的 MuJoCo 模型不少于 41 个 actuator；
- 1000 个仿真步无初始手部碰撞/数值异常；
- 固定版本、关键配置、策略文件与 Python 模块预检。

## 5. 仿真运行

```bash
cd "$HOME/Teleopit"
.venv/bin/python scripts/run/run_sim_rh56e2.py \
  controller.policy_path=ckpt/track_g1.onnx
```

原版 Teleopit 入口仍然可用：

```bash
.venv/bin/python scripts/run/run_sim.py \
  --config-name pico4_sim \
  controller.policy_path=ckpt/track_g1.onnx
```

## 6. 真机安装和只读预检

```bash
bash scripts/install.sh --profile real
```

给两只 RH56E2 配置不同 IP。手册默认地址是 `192.168.11.210:6000`，因此不能把两只保持相同出厂 IP 的手同时插入同一网络。之后执行：

```bash
$HOME/Teleopit/.venv/bin/python scripts/rh56e2_preflight.py \
  --teleopit-dir "$HOME/Teleopit" \
  --profile real --hardware \
  --left-host 192.168.11.210 \
  --right-host 192.168.11.211 \
  --port 6000
```

该预检只使用 Modbus FC03 读取，不会执行 FC16。必须看到两侧角度/力/电流数据、六路故障全为 0，且温度不超过配置阈值。

若设备拒绝 `unit_id=255`，可以在确认固件要求后尝试 `--unit-id 1`；正式配置也要同步修改 `hands.rh56e2.unit_id`。

## 7. 真机分阶段运行

先完成 [真机控制检查](真机控制检查.md) 中的 A–D 阶段。确认人员、急停、支撑架和空间安全后运行：

```bash
ENABLE_G1_REAL=YES ENABLE_RH56E2_WRITES=YES \
LEFT_HAND_IP=192.168.11.210 RIGHT_HAND_IP=192.168.11.211 \
NETWORK_INTERFACE=eth0 \
bash scripts/run_real.sh
```

入口会再次做只读预检，然后把以下显式覆盖传给 Teleopit：

```text
hands.driver=rh56e2_modbus_tcp
hands.rh56e2.write_enabled=true
real_robot.network_interface=<指定网卡>
```

运行中若 PICO 手帧超过 0.25 秒未更新，驱动向六路写入 `-1`，保持当前关节目标；检测到故障或温度超过 70°C 时拒绝继续写入。

## 8. 常见问题

| 现象 | 检查 |
|---|---|
| 找不到 `track_g1.onnx` | 重新运行安装且不要使用 `--skip-assets` |
| PICO 没有数据 | 同网段、防火墙、APK 版本、手势/手柄自动切换 |
| 第二只手连不上 | 两只手是否仍为同一个出厂 IP |
| FC03 超时 | IP/端口、网线、24 V、unit ID、主机静态 IP |
| 预检故障非零 | 停止，查机械卡滞、过流、过温或电机/通信故障；不要绕过检查 |
| 真机入口拒绝运行 | 必须完成验收并同时设置两个 `YES` 确认变量 |
