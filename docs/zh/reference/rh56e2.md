# 因时 Inspire RH56E2 参考

## 支持范围

该集成支持左手、右手或双手组合，可用于 MuJoCo 仿真和 Modbus TCP 真机。每只手由 6 个执行器驱动 12 关节运动学模型。Teleopit 手部 worker 支持 PICO 连续手势和手柄夹爪两种输入模式。

## 六通道顺序

所有真机向量使用以下固定顺序：

| 索引 | 通道 | somehand 驱动关节 |
| ---: | --- | --- |
| 0 | 小指 | `pinky_proximal_joint` |
| 1 | 无名指 | `ring_proximal_joint` |
| 2 | 中指 | `middle_proximal_joint` |
| 3 | 食指 | `index_proximal_joint` |
| 4 | 拇指弯曲 | `thumb_proximal_pitch_joint` |
| 5 | 拇指旋转 | `thumb_proximal_yaw_joint` |

原始位置 `0` 表示闭合，`1000` 表示张开。数值 `-1` 编码为 `0xFFFF`，用于固件的保持/不改变命令。连续控制前必须在每只真手上核对模型关节范围和方向。

## Modbus TCP 寄存器

| 用途 | 十进制 | 十六进制 | 功能码 |
| --- | ---: | ---: | --- |
| 目标角度 | 1486 | `0x05CE` | FC16 写 6 寄存器 |
| 目标速度 | 1522 | `0x05F2` | FC16 写 6 寄存器 |
| 实际角度 | 1546 | `0x060A` | FC03 读 6 寄存器 |
| 实际力 | 1582 | `0x062E` | FC03 读 6 寄存器 |
| 实际电流 | 1594 | `0x063A` | FC03 读 6 寄存器 |
| 故障 | 1606 | `0x0646` | FC03 读 3 寄存器/6 字节 |
| 状态 | 1612 | `0x064C` | FC03 读 3 寄存器/6 字节 |
| 温度 | 1618 | `0x0652` | FC03 读 3 寄存器/6 字节 |

默认端点为 `192.168.11.210:6000`，Unit ID 为 `255`（`0xFF`）。多只手可能具有相同出厂地址。必须一次配置和测试一只手，为双手分配唯一地址，不能把两个相同端点接到同一子网。

## 集成文件

```text
overlay/teleopit/sim2real/hands/rh56e2_protocol.py
overlay/teleopit/sim2real/hands/rh56e2.py
overlay/teleopit/configs/pico4_sim2real_rh56e2.yaml
overlay/teleopit/configs/pico4_sim_rh56e2.yaml
overlay/teleopit/configs/robot/g1_rh56e2.yaml
overlay/assets/robots/unitree_g1/g1_29dof_rh56e2.xml
overlay/third_party/somehand/configs/retargeting/{left,right,bihand}/
overlay/third_party/somehand/assets/mjcf/inspire_rh56e2_{left,right}/
```

somehand 模型把 21 个地标转换为关节弧度；Teleopit 选择六个驱动关节并映射到真机范围。真机驱动不会启动第二个 pico-bridge 接收器。

## 配置

真机配置的关键字段为：

```yaml
hands:
  enabled: true
  driver: rh56e2_modbus_tcp
  mode: vr_hand_pose
  sides: [left, right]
  rate_hz: 30.0
  frame_timeout_s: 0.25
  rh56e2:
    left_host: 192.168.11.210
    right_host: 192.168.11.211
    port: 6000
    unit_id: 255
    write_enabled: false
    max_temperature_c: 70
    open_on_failure: false
    open_on_shutdown: false
```

安装、配网和遥测检查期间保持 `write_enabled: false`。`scripts/run/run_sim2real_rh56e2.sh` 是受支持的门控入口，只有两个真机环境确认都存在时才会开启写入。

## 分阶段验证

1. 不接真机完成离线验证。
2. 运行双手 MuJoCo 仿真，确认左右和方向映射。
3. 只连接一只空载手，运行只读遥测。
4. 使用受保护工作台工具，以小增量测试一个自由度。
5. 对第二只手重复，再运行双手只读遥测。
6. 独立验证 G1 dry-run 和单独站立。
7. 只有现场有人操作急停且区域清空时，才运行组合控制。

精确命令和停止条件见[完整使用手册](../usage.md)。

## 安全行为与限制

- 代码和 YAML 中的写入默认均为关闭。
- 故障字节非零或温度超过配置阈值时阻止写入。
- 跟踪过期/缺失时保持各通道，不臆造姿态。
- 最小变化量和频率门控用于减少重复流量，不是安全等级限幅器。
- `open_on_failure` 和 `open_on_shutdown` 默认关闭，因为带负载时自动松手可能危险。
- 当前实现通过源码级测试，但没有认证具体手、固件、电源、负载或工作区。
